## Using these prompts

Prompts provide reusable instructions for a conversation. They do not automatically install skills, monitor activity, send messages, or change calendars. Health Compass provides general habit support, not medical care.

## Collection maintenance

Each listed skill must have a complete public prompt, a direct clickable text link, and a matching clickable QR image. Keep these destinations aligned when updating a prompt. The QR codes were decoded against their intended prompt URLs at full size and 300 pixels on November 5, 2026.
